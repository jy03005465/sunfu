# 改编检查清单

> 入口：[知识库目录](./index.md) ｜ 按 [02 改编全流程](./02-改编全流程.md) 的阶段组织

各阶段可勾选的 checklist。复制到项目里逐项打勾使用。

## ① 选品评估（对应 [03 IP 评估与选品](./03-IP评估与选品.md)）
- [ ] 热度数据达标（点击/收藏/订阅/完结度）
- [ ] 有清晰主线，非流水账
- [ ] 主角动机明确、配角立得住
- [ ] 爽点可视听化（非纯内心 OS/数据面板）
- [ ] 体量可压缩、支线可砍
- [ ] 设定与价值观可过审
- [ ] 作者配合度可接受
- [ ] 已用打分框架评分并过阈值
- [ ] 已确定最适配的改编媒介

## ② 版权与授权（对应 [04 版权与授权](./04-版权与授权.md)）
- [ ] 明确所需权利（改编/摄制/网络传播/衍生）
- [ ] 授权媒介范围逐项写清
- [ ] 期限、地域、独家性约定清楚
- [ ] 改编自由度/审稿机制约定
- [ ] 分成模式确定
- [ ] 衍生权与优先权归属明确
- [ ] 授权链完整、有作者原始授权证明

## ③ 改编立项
- [ ] 确定改编方向（媒介）
- [ ] 确定改编立场（还原/重构/魔改）
- [ ] 确定目标受众与体量规模
- [ ] 预算与回收预期清晰
- [ ] 完成项目策划案 / 改编 Bible

## ④ 剧作开发（对应 [05](./05-剧本改编核心方法.md)/[06](./06-人物改编要点.md)/[07](./07-叙事与结构转换.md)）
- [ ] 已拆书：主线表/人物谱/爽点节点表/设定表
- [ ] 已识别 IP 的"核"
- [ ] 删：砍掉无关支线与注水
- [ ] 并：合并重复配角/事件
- [ ] 改：内心戏外化、设定融入剧情、时间线重排
- [ ] 增：补衔接戏、补动机与情感铺垫
- [ ] 主角动机/弧光扎实
- [ ] 反派动机/实力合理
- [ ] 按媒介体量完成分集/分话/分幕
- [ ] 每单元有钩子—推进—留扣

## ⑤ 制作（分媒介，见各 [媒介页](./01-改编类型全景.md)）
- [ ] 选角/CV/人设贴合原著（[06 人物改编要点](./06-人物改编要点.md)）
- [ ] 视觉/听觉设定定调（[动画](./媒介-动画改编.md)/[漫画](./媒介-漫画改编.md)/[广播剧](./媒介-广播剧与有声书.md)）
- [ ] 玩法与系统设计（仅 [游戏](./媒介-游戏改编.md)）
- [ ] 制作预算与排期可控

## ⑥ 后期/打磨
- [ ] 节奏复核（无拖沓/无断裂）
- [ ] 音乐/特效/音效到位

## ⑦ 发行上线
- [ ] 排播/上线计划
- [ ] 与原著粉的预期沟通与宣发
- [ ] 合规终审通过

## ⑧ 衍生与复盘
- [ ] IP 矩阵下一环规划（[01 改编类型全景](./01-改编类型全景.md)）
- [ ] 数据/口碑复盘，回填 [案例库](./案例库.md)

## 通用避坑自查
- [ ] 是否守住 IP 的核（防魔改）
- [ ] 是否避免照搬注水/念设定
- [ ] 是否做了内心戏外化
- [ ] 详见 [常见坑与争议](./常见坑与争议.md)
