# 媒介 · 游戏改编

> 入口：[知识库目录](./index.md) ｜ 类型定位：[01 改编类型全景](./01-改编类型全景.md)

把网文 IP 改成游戏（手游/端游/独立游戏）。变现能力最强、互动最深，但"故事"与"玩法"的融合最难——这是游戏改编区别于其他媒介的根本。

## 定位与适配题材
- **优势**：商业变现能力最强（内购/付费）、玩家深度参与、IP 生命周期长。
- **最适配**：世界观宏大、系统设定清晰的题材（修仙的境界体系、玄幻的功法、卡牌可拆解的角色谱）。
- **挑战**：研发周期长、成本高、需把"线性故事"转成"可交互系统"。

## 改编要点（与线性媒介根本不同）

### 1. 叙事服务于玩法
- 其他媒介观众被动接收；游戏玩家主动操作。**故事要拆成可玩的系统、关卡、任务**。
- 网文的"升级打怪"天然契合游戏的成长/数值系统——这是网文改游戏的最大优势。

### 2. 世界观与设定的系统化
- 把原著设定转成游戏机制：境界 → 等级系统；功法 → 技能树；门派 → 阵营；法宝 → 装备。
- 设定越清晰自洽，越好系统化（呼应 [03 IP 评估与选品](./03-IP评估与选品.md) 的设定维度）。

### 3. 角色与养成绑定
- 主要角色转为可获取/养成对象（卡牌/伙伴），人设与技能/数值绑定（见 [06 人物改编要点](./06-人物改编要点.md)）。

### 4. 非线性叙事
- 主线剧情 + 支线任务 + 玩家选择，叙事结构从线性转为网状（见 [07 叙事与结构转换](./07-叙事与结构转换.md) 的视角/结构）。

### 5. 还原与原创的平衡
- 既要让原著粉认出 IP（场景/角色/名场面），又要满足游戏性，避免"挂着 IP 名的换皮游戏"（见 [常见坑与争议](./常见坑与争议.md)）。

## 制作流程要点
- 立项 → 玩法/系统设计 → 世界观与剧情文案 → 美术/程序研发 → 测试调优 → 上线运营。
