# 00 · 改编总览

> 入口：[知识库目录](./index.md)

## 一句话定义

**网络小说改编**：将连载于网络的长篇小说 IP，转译成另一种媒介形态（影视剧、短剧、动画、漫画、游戏、广播剧等）的创作与商业行为。它既是**内容再创作**，也是**IP 价值的二次开发与变现**。

## 为什么要改编（驱动力）

1. **现成的故事与人设**：网文经过连载市场检验，已有完整世界观、人物、爽点和情节骨架，降低原创剧本的题材风险。
2. **自带粉丝盘**：头部网文有庞大读者基础，是天然的"首批观众/付费用户"。
3. **IP 一鱼多吃**：一个 IP 可同时/分阶段开发影视、动画、漫画、游戏、衍生品，形成矩阵。
4. **平台内容饥渴**：长视频、短剧、动画平台对成熟内容有持续采买需求。

| 矛盾 | 说明 | 对应方法页 |

## IP 改编价值链（从文字到成片/成品）

```
网文连载 → IP评估选品 → 版权采买/授权 → 改编立项 →
剧本/剧作开发 → 制作(拍摄/作画/研发) → 后期 → 发行上线 → 衍生开发
```

## 三种典型改编立场

1. **高还原**：尽量忠于原著情节与人设，主攻原著粉。风险：体量/节奏/合规难压缩。
2. **取核重构（推荐主流）**：保留 IP 的"核"（核心人设、核心爽点、核心世界观），重构枝节以适配媒介。
3. **借壳魔改**：只借用 IP 名气，故事大改。风险：口碑反噬，见 [常见坑与争议](./常见坑与争议.md)。
