# 02 · 改编全流程

> 入口：[知识库目录](./index.md) ｜ 上一页：[01 改编类型全景](./01-改编类型全景.md)

从一部网文到最终成片/成品，端到端的阶段、产出物与关键决策点。该流程跨媒介通用，分媒介差异见各 [媒介页](./01-改编类型全景.md)。

## 全流程总图

```
① 选品评估 → ② 版权采买 → ③ 改编立项 → ④ 剧作开发 →
⑤ 制作 → ⑥ 后期/打磨 → ⑦ 发行上线 → ⑧ 衍生与复盘
```

## 各阶段拆解

### ① 选品评估（Pre-IP）
- **做什么**：在海量网文里筛选可改编标的，评估改编价值与难度。
- **产出物**：IP 评估报告、改编可行性结论。
- **要点页**：[03 IP 评估与选品](./03-IP评估与选品.md)。

### ② 版权采买与授权
- **做什么**：与作者/平台谈版权，明确改编权范围、期限、媒介、分成。
- **产出物**：版权授权合同。
- **风险**：授权链不清、一权多卖、改编权与衍生权混淆。详见 [04 版权与授权](./04-版权与授权.md)。

### ③ 改编立项
- **做什么**：确定改编方向（哪种媒介）、改编立场（还原/重构/魔改）、目标受众、体量规模、预算。
- **产出物**：项目策划案、改编大纲（Bible）。
- **关键决策**：还原 vs 重构（见 [00 改编总览](./00-改编总览.md) 的"三种立场"）。

### ④ 剧作开发（最关键的创作阶段）
- **做什么**：把小说转成剧本/分镜脚本/游戏文案。
- **子步骤**：
  1. **拆书**：通读原著，提炼主线、人物谱、爽点节点、世界观设定。
  2. **重构大纲**：确定保留/删除/合并/新增的情节。
  3. **分集/分幕**：按媒介体量切分（剧集分集、动画分话、短剧分集）。
  4. **写台本**：场景、对白、动作、镜头提示。
- **产出物**：故事大纲 → 分集大纲 → 分场 → 完整剧本。
- **要点页**：[05 剧本改编核心方法](./05-剧本改编核心方法.md)、[06 人物改编要点](./06-人物改编要点.md)、[07 叙事与结构转换](./07-叙事与结构转换.md)。

### ⑤ 制作
- 影视：选角、置景、拍摄；动画：设定、分镜、作画、配音；游戏：美术、程序、关卡。
- 分媒介细节见对应 [媒介页](./01-改编类型全景.md)。

### ⑥ 后期/打磨
- 剪辑、特效、音乐、调色；动画合成；游戏测试调优。

### ⑦ 发行上线
- 平台排播、宣发、与原著粉的预期沟通。

### ⑧ 衍生与复盘
- IP 矩阵延展（见 [01 改编类型全景](./01-改编类型全景.md)）、口碑/数据复盘。
