# 05 · 剧本改编核心方法

> 入口：[知识库目录](./index.md) ｜ 全流程位置：[02 改编全流程](./02-改编全流程.md) 阶段④

这是改编中**最核心的创作页**。把几十上百万字的网文转成有限体量的剧本/脚本，本质是四个动作：**删、并、改、增**。

## 第一步：拆书（建立改编地图）

动笔改之前必须先"拆解"原著，产出四张表：

1. **主线表**：核心目标 + 阶段性目标 + 高潮节点。
2. **人物谱**：主角/核心配角/反派的动机、关系、弧光（详见 [06 人物改编要点](./06-人物改编要点.md)）。
3. **爽点节点表**：原著最受读者认可的高光/反转/打脸点（哪些必须保留）。
4. **世界观设定表**：必要设定 vs 可省略设定。

> 拆书的目标：找出 IP 的"**核**"——拿掉就不是这个故事的东西。核之外都可动。

## 第二步：四个核心动作

### 删（做减法，最重要）
- 砍掉：与主线无关的支线、重复的"升级/打怪"循环、过渡性日常。
- 原则：**保留推动主线和塑造人物的情节**，其余优先删。
- 网文常见的"注水"和重复套路是删减重点。

### 并（合并同类项）
- 多个功能相似的配角合并为一个更立体的角色。
- 多个相似事件合并为一场更高浓度的戏。
- 分散的信息集中到一场关键戏里交代。

### 改（转译与适配）
- 把"内心独白/系统面板/旁白叙事"改为**可被看见/听见的外化表达**（动作、对白、冲突）。详见 [07 叙事与结构转换](./07-叙事与结构转换.md)。
- 调整不合理或不合规的设定。
- 重排时间线，让因果更紧凑。

### 增（必要的新增）
- 为被删支线"善后"，补衔接戏。
- 增加原著缺失的人物动机、情感铺垫。
- 为媒介特性新增内容（如影视的视觉名场面、短剧的钩子）。

## 第三步：重构结构

把整理后的素材按目标媒介体量切分：

```
故事大纲 → 分集/分话/分幕大纲 → 分场 → 完整台本
```

- 每一集/话都要有**钩子（开头抓人）+ 推进（中段)+ 留扣（结尾悬念）**。
- 结构转换的节奏问题见 [07 叙事与结构转换](./07-叙事与结构转换.md)。

## 改编的黄金平衡

```
忠于原著的"核"  ←————————→  适配媒介与大众
   (留住原著粉)                (破圈吸新观众)
```

- 偏左过头：还原但冗长、节奏差、难破圈。
- 偏右过头：魔改、口碑反噬（见 [常见坑与争议](./常见坑与争议.md)）。
- 主流推荐：**取核重构**（见 [00 改编总览](./00-改编总览.md)）。
