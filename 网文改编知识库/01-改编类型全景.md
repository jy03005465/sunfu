# 01 · 改编类型全景

> 入口：[知识库目录](./index.md) ｜ 上一页：[00 改编总览](./00-改编总览.md)

网文 IP 的六大主流改编方向。每个方向都有专门的要点页，本页给出**定位、优势、典型适配题材**的对照，帮你选对改编方向。

## 六大方向对照

| 方向 | 篇幅/形态 | 核心优势 | 最适配的网文题材 | 详细要点 |
|------|-----------|----------|------------------|----------|
| **影视剧** | 长剧集/电影 | 投资大、破圈强、商业天花板高 | 言情、古装、悬疑、现实、群像权谋 | [媒介·影视剧改编](./媒介-影视剧改编.md) |
| **网络短剧** | 单集 1–3 分钟、几十到上百集 | 周期短、成本低、爽点密度高、变现快 | 强爽文：逆袭、复仇、霸总、战神、重生 | [媒介·网络短剧改编](./媒介-网络短剧改编.md) |
| **动画（国漫）** | 番剧/院线 | 表现超现实设定无上限、受众年轻 | 玄幻、修仙、热血、奇幻、机甲 | [媒介·动画改编](./媒介-动画改编.md) |
| **漫画** | 条漫/页漫连载 | 成本最低、可作 IP 试水与预热 | 几乎全题材，尤其视觉冲击强的 | [媒介·漫画改编](./媒介-漫画改编.md) |
| **游戏** | 手游/端游/独立游戏 | 变现能力最强、强互动 | 世界观宏大、系统设定清晰（修仙/卡牌/养成）| [媒介·游戏改编](./媒介-游戏改编.md) |
| **广播剧/有声书** | 音频连载 | 成本极低、还原度高、粉丝粘性强 | 言情、耽改向、对白驱动型 | [媒介·广播剧与有声书](./媒介-广播剧与有声书.md) |

## 怎么选改编方向（决策要点）

先问三个问题：

1. **IP 的核心爽点靠什么承载？**
   - 靠强情绪反转/打脸 → 短剧、影视
   - 靠视觉奇观/战斗设定 → 动画、游戏、漫画
   - 靠人物关系/对白氛围 → 广播剧、言情剧
2. **预算与回收周期？**
   - 低成本快回收 → 短剧、漫画、广播剧（常作"试水"）
   - 大投入博破圈 → 影视剧、院线动画
3. **想做单点变现还是 IP 矩阵？**
   - 单点 → 选最适配的一种
   - 矩阵 → 见下文

## IP 改编矩阵（一鱼多吃）

成熟运营常采用"**漫画/广播剧预热 → 动画或短剧扩圈 → 影视剧/游戏收割**"的阶梯：

```
       漫画/有声书（低成本试水、积累粉丝）
                  │
                  ▼
        动画 / 短剧（中成本扩大受众）
                  │
                  ▼
     影视剧 / 游戏（高成本、商业收割 + 衍生品）
```

- 选品时即考虑矩阵潜力，见 [03 IP 评估与选品](./03-IP评估与选品.md)
- 不同媒介共享 IP 时的授权拆分，见 [04 版权与授权](./04-版权与授权.md)
