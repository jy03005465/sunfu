# 术语表

> 入口：[知识库目录](./index.md)

改编相关高频术语速查。按主题分组，并指向详细页面。

## IP 与版权
- **IP**：Intellectual Property，知识产权，此处指可被开发的网文作品及其角色/世界观。
- **改编权**：将作品改成其他体裁的权利。详见 [04 版权与授权](./04-版权与授权.md)。
- **摄制权**：将作品拍成影视的权利。
- **信息网络传播权**：在网络平台传播作品的权利。
- **衍生开发权**：开发游戏、漫画、周边、续作等的权利。
- **买断 / 保底+分成 / 纯分成**：三种常见版权付费模式。
- **授权链**：作者 → 平台 → 改编方的权利传递链条，须完整可证。

## 选品与评估
- **可改编性**：一部网文转成其他媒介的难易程度。详见 [03 IP 评估与选品](./03-IP评估与选品.md)。
- **头部 / 腰部作品**：按热度数据划分的作品层级。
- **金手指**：网文中让主角开挂的设定（系统、重生、特殊能力等）。
- **爽点**：让读者获得情绪满足的情节（打脸、逆袭、升级等）。

## 创作与剧作
- **拆书**：通读并解构原著，提炼主线/人物/爽点/设定。详见 [05 剧本改编核心方法](./05-剧本改编核心方法.md)。
- **核**：IP 中拿掉就不成立的核心要素（人设/爽点/世界观）。
- **删并改增**：剧本改编的四个核心动作。
- **弧光 / 人物弧光**：角色在故事中的成长与转变曲线。详见 [06 人物改编要点](./06-人物改编要点.md)。
- **内心戏外化**：把内心独白转成对白/动作/视觉。详见 [07 叙事与结构转换](./07-叙事与结构转换.md)。
- **Bible / 故事圣经**：项目的世界观/人物/设定总纲文档。
- **分集大纲 / 分场**：剧本的中间产出层级。

## 节奏与结构
- **钩子（hook）**：抓住观众注意力的强冲突/悬念点。
- **留扣 / 留悬念**：单元结尾设置的悬念，吸引继续观看。
- **爽点密度**：单位时长内爽点出现的频率。短剧最高。详见 [07 叙事与结构转换](./07-叙事与结构转换.md)。
- **卡点付费**：短剧在钩子前设置付费解锁。详见 [媒介·网络短剧改编](./媒介-网络短剧改编.md)。

## 分媒介术语
- **番剧 / 话**：动画的连载形态与单元。详见 [媒介·动画改编](./媒介-动画改编.md)。
- **分镜（storyboard）**：把脚本转成镜头序列的画面草图。
- **条漫**：竖屏纵向滑动阅读的漫画。详见 [媒介·漫画改编](./媒介-漫画改编.md)。
- **CV / 声优**：配音演员。详见 [媒介·广播剧与有声书](./媒介-广播剧与有声书.md)。
- **广播剧 / 有声书**：两种音频改编形态。
- **换皮**：只套用 IP 名而内容无关的开发（贬义）。详见 [常见坑与争议](./常见坑与争议.md)。
- **IP 矩阵 / 一鱼多吃**：同一 IP 多媒介分阶段开发。详见 [01 改编类型全景](./01-改编类型全景.md)。
- **破圈**：内容触达原著粉以外的大众受众。
