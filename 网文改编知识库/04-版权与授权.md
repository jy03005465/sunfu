# 04 · 版权与授权

> 入口：[知识库目录](./index.md) ｜ 全流程位置：[02 改编全流程](./02-改编全流程.md) 阶段②

> ⚠️ 本页为通识性整理，**非法律意见**。实际签约务必咨询专业版权律师。

选好了 IP（见 [03 IP 评估与选品](./03-IP评估与选品.md)），下一步是拿到合法的改编权。版权没谈清楚，后面投入越大风险越大。

## 几个必须分清的权利

网文 IP 的著作权可拆分授权，**不要笼统说"买了版权"**：

| 权利 | 含义 | 注意 |
|------|------|------|
| **改编权** | 改成其他体裁（剧本、动画脚本等） | 要写明可改成"哪种媒介" |
| **摄制权** | 拍成影视作品 | 与改编权常一起授予，但概念不同 |
| **信息网络传播权** | 在网络平台传播 | 短剧/网络平台必备 |
| **衍生开发权** | 游戏、漫画、周边、续作等 | IP 矩阵的关键，见 [01 改编类型全景](./01-改编类型全景.md) |
| **署名权等人身权** | 不可转让 | 作者始终保留 |

## 授权关键条款（谈判清单）

1. **授权媒介范围**：影视 / 短剧 / 动画 / 漫画 / 游戏 / 有声，逐项明确，避免"打包模糊"。
2. **授权期限与地域**：多少年、哪些地区、能否续约。
3. **独家 vs 非独家**：是否排他。
4. **改编自由度**：能改多大？是否需作者审稿？是否限制"魔改"？（与 [常见坑与争议](./常见坑与争议.md) 直接相关）
5. **分成模式**：一次性买断 / 保底 + 分成 / 纯分成。
6. **衍生权归属与优先权**：续作、其他媒介的优先开发权。
7. **授权链证明**：确认对方确实有权授权（作者 ↔ 平台 ↔ 你）。

## 常见法律风险

| 风险 | 表现 | 防范 |
|------|------|------|
| **授权链断裂** | 平台无权代作者授权某项权利 | 要求出示作者→平台的原始授权文件 |
| **一权多卖** | 同一改编权重复授权多方 | 约定独家、登记备案 |
| **权利范围超用** | 只买了改编权却拿去做游戏 | 严格在授权范围内开发 |
| **二次创作侵权** | 改编中加入他人受保护元素 | 原创或另行获授权 |
| **作者人身权冲突** | 魔改损害作者声誉引纠纷 | 合同约定改编尺度与审稿机制 |
