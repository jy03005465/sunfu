# 媒介 · 动画改编

> 入口：[知识库目录](./index.md) ｜ 类型定位：[01 改编类型全景](./01-改编类型全景.md)

把网文改成动画（番剧或院线国漫）。动画对超现实设定的表现力没有上限，是玄幻/修仙/热血题材的理想载体。

## 定位与适配题材
- **优势**：可呈现真人难以实现的奇观（法术、神兽、宏大场面），受众年轻、粘性高。
- **最适配**：玄幻、修仙、奇幻、热血、机甲、东方幻想。
- **挑战**：制作周期长、作画成本高、产能受限。

## 改编要点

### 1. 视觉设定先行
- **世界观与角色设定（设定集/人设图）是第一步**：服化、法宝、场景、能力特效都要先美术定调。
- 设定的取舍延续 [03 IP 评估与选品](./03-IP评估与选品.md) 与 [05 剧本改编核心方法](./05-剧本改编核心方法.md)。

### 2. 分话与"话末高潮"
- 番剧以"话"为单元（约 20 分钟），每话末要有高潮/转折留住追番观众（见 [07 叙事与结构转换](./07-叙事与结构转换.md)）。

### 3. 战斗/奇观的呈现
- 网文的"变强/斗法"靠文字渲染，动画靠**分镜 + 作画 + 特效 + 音效**制造燃点，这是国漫的核心竞争力，也是成本大头。

### 4. 声优与角色
- 配音是角色塑造的重要部分（与 [广播剧](./媒介-广播剧与有声书.md) 相通）。

### 5. 季番规划
- 长篇网文常分多季改编，需规划每季的故事弧与悬念。

## 制作流程要点
- 剧本/脚本 → 分镜（storyboard）→ 设定/原画 → 作画 → 上色合成 → 配音/配乐。
