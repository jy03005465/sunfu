# 媒介 · 漫画改编

> 入口：[知识库目录](./index.md) ｜ 类型定位：[01 改编类型全景](./01-改编类型全景.md)

把网文改成漫画（多为竖屏条漫，也有页漫）。成本最低、上线最快，常作为 IP 的"**试水与预热**"环节，为后续动画/影视积累粉丝。

## 定位与适配题材
- **优势**：成本/周期低、可快速验证 IP 的视觉化潜力、作为 IP 矩阵的前哨（见 [01 改编类型全景](./01-改编类型全景.md) 的矩阵）。
- **适配**：几乎全题材，视觉冲击强、人设鲜明的尤佳。

## 改编要点

### 1. 分镜与节奏
- **条漫**靠纵向滑动阅读，节奏由格子大小、留白、滑动停顿控制。
- 关键反转/名场面用大格/跨页强化冲击。
- 节奏密度介于短剧与番剧之间（见 [07 叙事与结构转换](./07-叙事与结构转换.md) 的密度对照）。

### 2. 人设辨识度
- 漫画靠造型、发色、表情区分角色，人设辨识度要高（见 [06 人物改编要点](./06-人物改编要点.md)）。

### 3. 文字与画面的分工
- 把网文旁白尽量转为画面 + 少量对白/旁白框；避免大段文字塞进格子（见 [07 叙事与结构转换](./07-叙事与结构转换.md) 的内心戏外化）。

### 4. 话与钩子
- 每话结尾留悬念吸引追更，连载逻辑与网文相通但更视觉化。

## 作为 IP 试水的价值
- 漫画数据（点击/追更/打赏）可反哺 [03 IP 评估与选品](./03-IP评估与选品.md)，验证是否值得投更重的动画/影视。
