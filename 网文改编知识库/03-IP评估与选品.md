# 03 · IP 评估与选品

> 入口：[知识库目录](./index.md) ｜ 全流程位置：[02 改编全流程](./02-改编全流程.md) 阶段①

选品是改编成败的第一道闸门——**烂 IP 选错方向，后面再努力也救不回来**。本页给出评估维度、打分框架和"易改/难改"信号。

## 评估的两个维度

改编价值 = **IP 自身价值** × **可改编性（改编难度的倒数）**。

光有热度但极难改编（体量过大、设定违规、爽点难视听化），不是好标的；反之，一个中等热度但"骨架干净、人设鲜明、爽点可视化"的 IP 往往更适合改。

## 维度一：IP 自身价值

| 指标 | 看什么 | 信号 |
|------|--------|------|
| **数据热度** | 点击、收藏、订阅、月票、完结率、书评数 | 头部/腰部作品优先 |
| **粉丝基础** | 读者规模、活跃度、二创数量 | 自带"首批观众" |
| **题材契合** | 是否踩中当下平台/市场风口 | 顺风口溢价高 |
| **完结度** | 是否完结、烂尾与否 | 完结作改编风险更可控 |
| **作者配合度** | 作者是否愿意配合改编、口碑 | 影响授权与后续宣发 |

## 维度二：可改编性（能不能改、好不好改）

这是网文人最容易忽视、却最决定成败的部分：

| 维度 | 易改信号 ✅ | 难改信号 ⚠️ |
|------|-------------|-------------|
| **主线清晰度** | 有清晰主线和阶段性目标 | 流水账、无明确主线、靠日常堆砌 |
| **人物** | 主角动机明确、配角立得住 | 主角全靠金手指、配角工具人 |
| **爽点形态** | 爽点靠情节/关系/反转 | 爽点全靠内心独白、数据面板、系统提示 |
| **体量** | 主线可压缩、支线可砍 | 几百万字且支线盘根错节 |
| **设定合规** | 价值观正向、设定可过审 | 涉敏感题材、价值观争议 |
| **视觉/听觉转化** | 场景、动作、奇观可被"看见/听见" | 大量抽象设定、纯文字推演 |

> 经验法则：**网文越依赖"读者脑补"和"内心 OS"来制造爽感，改编越难**。因为这些恰恰是镜头/画面/声音难以直接呈现的。转化方法见 [07 叙事与结构转换](./07-叙事与结构转换.md)。

## 选品打分框架（可直接用）

给每项 1–5 分，加权求和，设定阈值（如总分 ≥ 70% 才进入立项）：

```
总分 = 0.35 × IP价值分 + 0.45 × 可改编性分 + 0.20 × 商业/矩阵潜力分
```

- IP价值分：热度、粉丝、题材、完结度、作者配合
- 可改编性分：主线、人物、爽点形态、体量、合规、视听转化
- 商业/矩阵潜力分：能否一鱼多吃（见 [01 改编类型全景](./01-改编类型全景.md) 的 IP 矩阵）

## 选品 ↔ 媒介匹配

选品结论要直接指向"改成哪种媒介"：

- 强爽文、强反转 → [网络短剧](./媒介-网络短剧改编.md)
- 玄幻修仙、视觉奇观 → [动画](./媒介-动画改编.md) / [游戏](./媒介-游戏改编.md)
- 言情、权谋、群像 → [影视剧](./媒介-影视剧改编.md)
- 对白驱动、强 CP → [广播剧](./媒介-广播剧与有声书.md)
