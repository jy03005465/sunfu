# 案例库

> 入口：[知识库目录](./index.md)

用"模式化案例"拆解改编的成败规律。下面按**改编模式**归纳常见的成功/失败范式，并指向对应方法页——重点是**可迁移的规律**，而非追逐具体片名。

> 说明：本页以"模式"而非"点名具体作品"的方式整理，便于复用。补充真实案例时，请挂到对应模式下并标注成败原因。

## 成功范式

### S1 · 取核重构型成功
- **模式**：保留 IP 核心人设/爽点/世界观，大胆重构枝节、压缩体量、外化内心戏。
- **为什么成**：既留住原著粉的"魂"，又用媒介语言破圈。
- **关联**：[05 剧本改编核心方法](./05-剧本改编核心方法.md)、[07 叙事与结构转换](./07-叙事与结构转换.md)。

### S2 · 强爽文→短剧型成功
- **模式**：把强情绪网文提炼成高钩子密度的竖屏短剧，爽点前置加密。
- **为什么成**：题材与媒介高度匹配，转化路径短。
- **关联**：[媒介·网络短剧改编](./媒介-网络短剧改编.md)、[03 IP 评估与选品](./03-IP评估与选品.md)。

### S3 · 奇观题材→动画型成功
- **模式**：玄幻/修仙靠动画呈现真人难拍的奇观与战斗。
- **为什么成**：媒介补足了真人影视的表现短板。
- **关联**：[媒介·动画改编](./媒介-动画改编.md)。

### S4 · 矩阵阶梯型成功
- **模式**：漫画/广播剧预热 → 动画/短剧扩圈 → 影视/游戏收割。
- **为什么成**：低成本验证 + 逐级放大，风险可控。
- **关联**：[01 改编类型全景](./01-改编类型全景.md) 的 IP 矩阵。

## 失败范式

### F1 · 魔改崩盘型
- **模式**：核心人设/精神被改坏，只剩 IP 名。
- **为什么败**：原著粉反噬 + 大众无感，两头不讨好。
- **关联**：[常见坑与争议](./常见坑与争议.md) 第 1 条。

### F2 · 照搬注水型
- **模式**：几乎原样搬运，节奏拖沓、内心戏照念。
- **为什么败**：违反视听媒介节奏规律。
- **关联**：[07 叙事与结构转换](./07-叙事与结构转换.md)、[常见坑与争议](./常见坑与争议.md) 第 2、3 条。

### F3 · 换皮变现型
- **模式**：游戏/衍生品只蹭 IP 名，内容无关。
- **为什么败**：透支 IP 信用、粉丝不买账。
- **关联**：[媒介·游戏改编](./媒介-游戏改编.md)、[常见坑与争议](./常见坑与争议.md) 第 7 条。

### F4 · 选品/合规误判型
- **模式**：选了难改或难过审的 IP，投入后受阻。
- **为什么败**：源头评估缺位。
- **关联**：[03 IP 评估与选品](./03-IP评估与选品.md)、[04 版权与授权](./04-版权与授权.md)。
