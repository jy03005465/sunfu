# 当前版本与中国安卓市场正式上架之间的差距分析

本文档用于明确：**当前仓库里的展示版 App，距离正式上架中国安卓市场，还差哪些关键项。**

---

## 1. 可以直接用于展示的部分

当前已经具备：

- 可安装 APK
- 品牌化图标
- 启动页
- 离线单机核心玩法
- 商店展示图
- 商店中文文案
- 隐私政策草稿
- 设置页 / 新手引导 / 本地存档

这些内容已经足够：

- 给发行、设计、运营预览
- 做市场测试
- 内部试玩
- 准备上架资料初稿

但这并不等于已经满足中国安卓市场正式提审条件。

---

## 2. 当前最关键的缺口

### 2.1 主体资质未确认

正式上架国内主流安卓市场时，通常需要：

- 企业主体账号（多数市场更稳妥）
- 营业执照
- 开发者实名信息
- 联系方式

当前仓库中未固化这些内容。

### 2.2 隐私政策仍是草稿

当前已有：

- `marketing/privacy-policy.md`

但正式上架仍缺：

- 真实开发者名称
- 真实联系邮箱
- 公网可访问 URL
- 与最终 SDK/权限一致的版本

### 2.3 App 内隐私弹窗/同意机制未确认达标

中国安卓市场审核通常更看重：

- 首次启动即展示隐私政策/用户协议
- 明确“同意/不同意”
- 不同意后的处理逻辑
- 未同意前不应提前索取不必要权限

当前版本已有新手引导和设置页，但**不等于已经满足正式隐私弹窗合规要求**。

### 2.4 正式签名资料仍未落地

当前仓库已经支持：

- 读取 `android/key.properties`
- 读取签名相关环境变量
- 在缺少正式签名资料时回退到 debug 签名，便于测试

但正式上架前仍缺：

- 真实 keystore 文件
- 真实密码与 alias
- 正式签名后的最终发布包

### 2.5 游戏版号/软著状态未确认

这点对中国安卓市场尤其关键：

- 如果按“游戏”上架，多数市场会关注版号、软著、游戏资质
- 如果没有版号，很多主流市场的正式上架会受到限制

当前仓库里没有任何“已获版号 / 已获软著”的信息。

---

## 3. 可能影响上架的具体风险

### 高风险

- 没有隐私政策线上链接
- 没有正式签名
- 没有主体资质
- 将“游戏”提交到需要版号的渠道但没有版号

### 中风险

- 包名 `com.sunfu.game_app` 偏工程化，不够产品化
- 隐私弹窗和个人信息处理说明未最终定版
- 市场要求的补充资料（客服邮箱、开发者信息、截图规范）未补齐

### 低风险

- 商店截图可继续优化成真机截图
- 文案可再细化
- 版本号命名可更正式

---

## 4. 如果你想尽快上架，建议的实际顺序

### 路线 A：先做“资料合规化”

1. 确认主体（企业/个人）
2. 确认是否已有软著
3. 确认是否计划申请游戏版号
4. 完成隐私政策正式版与线上托管
5. 增加 App 内隐私同意弹窗
6. 配置正式签名

### 路线 B：先做“渠道策略判断”

先回答两个问题：

1. 你是要上 **主流手机厂商市场**，还是先上 **第三方渠道/官网分发**？
2. 你准备把它按 **游戏** 提交，还是按 **普通工具/益智应用** 去尝试？

这两个选择会直接影响版号与资质压力。

---

## 5. 最现实的建议

如果你的目标是“真正上中国安卓市场”，当前最应该先做的不是继续堆玩法，而是：

1. 明确主体资质
2. 明确版号/软著路径
3. 补隐私弹窗
4. 配正式签名
5. 统一包名、版本号、联系信息

这些完成之后，再去逐个市场提交，成功率会高很多。
