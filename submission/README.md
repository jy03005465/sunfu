## 4. 当前最需要优先处理的事项

如果你准备真实上架国内安卓市场，建议先优先确认：

1. 是否已有公司/个体开发者主体
2. 是否已有软件著作权
3. 当前版本是否需要补“首次启动隐私政策同意弹窗”
4. 是否需要做正式签名包
5. 是否打算按“游戏”身份提交，若是，是否涉及版号要求
