# sunfu

## 智能化转型与分布式智算能力框架

本框架面向智能化转型及分布式智算场景，帮助客户从自我认知、需求表达、方案甄选到转型执行持续提升决策质量。

### 需求侧能力

“我”需要具备以下能力：

1. 精准自知智能化转型及分布式智算需求的能力。
2. 精准表达智能化转型需求的能力。
3. 甄选智能化转型及分布式智算最优供给方案的能力。
4. 在转型过程中持续变得更加聪明、精明的能力。

### 供给侧能力：专属需智模型打造

专属需智模型需要提供以下能力：

1. 智能化转型意图识别及结构化建模的能力。
2. 从意图解析为转型所需能力模型的能力。
3. 智能化转型方案交互体验的能力。
4. 客户智能化转型数据安全、顺畅打标及调用的能力。

### 客户需要能力与供给能力对应表

| 客户需要的能力 | 对应生成的供给能力 |
| --- | --- |
| 精准自知智能化转型及分布式智算需求的能力 | 提供智能化转型意图识别及结构化建模能力，围绕客户业务现状、转型目标、分布式智算资源、数据基础和组织条件建立需求画像，帮助客户准确识别自身智能化转型缺口与优先级。 |
| 精准表达智能化转型需求的能力 | 提供从意图解析为转型所需能力模型的能力，将客户的业务语言、管理诉求和场景目标转译为可交付的能力模型，明确数据、模型、算力、流程、应用和安全等转型要素。 |
| 甄选智能化转型及分布式智算最优供给方案的能力 | 提供智能化转型方案交互体验能力，支持多方案生成、对比、推演和评估，帮助客户从成本、收益、落地周期、技术适配度、风险和扩展性等维度选择最优供给方案。 |
| 在转型过程中持续变得更加聪明、精明的能力 | 提供客户智能化转型数据安全、顺畅打标及调用能力，将转型过程中的需求、反馈、评估、使用和运营数据持续沉淀为专属需智模型资产，形成可迭代、可复用、可优化的智能化转型闭环。 |
